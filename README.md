# 🧥 의류 물류 창고 WMS 시스템 "Styleboso"

## 🧾 프로젝트 개요

**Styleboso**는 AWS 기반 클라우드 환경에서 배포된 **웹 기반 의류 물류 관리 시스템 (WMS)** 입니다.  
기존 수기 작업으로 관리되던 입출고, 재고 정보, 거래처 등을 웹 애플리케이션으로 통합 관리하여 **업무 효율성과 정확성 향상**을 목표로 개발되었습니다.

<br>

## 🎯 기획 의도

- 아날로그 방식으로 관리되던 **의류 재고 및 입출고 관리 업무의 디지털화**
- **창고 관리자 및 운영자**가 직관적인 UI로 재고 현황을 확인하고 처리할 수 있도록 지원
- **AWS 기반 클라우드 배포**를 통한 실제 서비스 환경 모의 구현

<br>

## 👨‍👩‍👧‍👦 팀원 역할 및 주요 업무

### 👑 팀장
- 프로젝트 전체 일정 조율 및 문서 관리 (간트차트, 회의록 등)
- GitHub Repository 관리
- 발표 자료 및 발표 총괄

### 🧠 프로젝트 기획 및 설계
- WMS 비즈니스 프로세스 설계
- ERD 및 테이블 정의서 작성
- 기능 흐름도 및 시스템 구조 설계

### ☁ AWS 클라우드 운영
- **AWS EC2 인스턴스** 기반 애플리케이션 배포
- AWS를 활용한 보안 설정 및 접근 제어

### 🎨 프론트엔드
- HTML / CSS 기반의 UI 화면 구현
- jQuery를 이용한 인터페이스 동작 처리

### 🔎 주요 기능 구현
- **페이징 처리**: 대용량 데이터에 대한 효율적 접근
- **검색 기능**: 품목명, 거래처명 등 조건 검색 처리
- **Spring Boot + Ajax 기반 CRUD**:
  - 창고, 품목, 거래처 등록 / 수정 / 삭제
  - 입력 값에 대한 **유효성 검사 처리**
